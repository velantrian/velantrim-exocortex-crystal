# مسرد Crystal وضوابط الادعاءات

- **physical L3**: طبقة تخزين متعددة الحالات، وليست تلقائياً **strict Canon**.
- **retrieval score**: إشارة ترتيب وليست evidence.
- **model output**: مادة مولدة وليست source truth.
- **migration proof**: دليل تكافؤ النقل، وليس claim proof.
- **SQLite**: الملف المحلي النشط المعتاد.
- **Mock**: backend صريح للتطوير وCI.
- **PostgreSQL/pgvector**: هدف اختياري غير نشط مع `active=false`؛ import success ليس activation.
- **Reader Core**: طبقة قراءة مخصصة مخططة وغير منفذة.
- **NLnet**: submitted / under review / not awarded.
- **€50,000 تقريباً**: تخطيط فقط، وليس ميزانية معتمدة أو التزام دفع؛ budget change: none.
- **baseline**: العمل المدمج قبل الاتفاق ولا يجوز احتسابه مرة أخرى كـ funded delta.
- لا تُدّعى شهادة قانونية أو GDPR أو أمنية أو native-speaker editorial certification.
