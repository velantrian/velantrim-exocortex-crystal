# التوثيق العربي

الإنجليزية هي لغة المصدر والعمل والمرجع عند التعارض. الملفات العربية واجهة عامة مُصانة، لكنها لا تنشئ سلطة مستقلة على التنفيذ أو Guardian أو TruthGate أو strict Canon أو الأمن أو المنحة.
