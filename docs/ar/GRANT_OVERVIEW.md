# نظرة عامة على المشروع والمنحة والحوكمة

Crystal بنية محلية أولاً للذاكرة والأدلة وحدود القرار في أنظمة الذكاء الاصطناعي القابلة للتدقيق.

```text
physical L3 != strict Canon
retrieval score != evidence
model output != source truth
migration proof != claim proof
import success != activation
```

SQLite هو الملف المحلي النشط المعتاد. Mock خلفية صريحة للتطوير وCI. PostgreSQL/pgvector هدف اختياري غير نشط مع `active=false`؛ نجاح الاستيراد لا يعني التفعيل.

اقتراح NLnet مُقدَّم وقيد المراجعة ولم تُمنح المنحة. مبلغ نحو €50,000 هو تخطيط للطلب وليس ميزانية معتمدة أو التزام دفع. تغيير الميزانية: لا شيء. العمل المدمج قبل اتفاق المنحة هو خط أساس قائم ولا يجوز احتسابه مرة أخرى كعمل ممول.

Reader Core غير منفذ. لا توجد شهادة قانونية أو GDPR أو أمنية، ولا شهادة تحرير من متحدث أصلي.
