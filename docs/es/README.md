## 🔒 Regla de traducción y autoridad

Estas páginas son una orientación mantenida en español para reviewers,
instituciones y personas colaboradoras. No modifican el runtime ni el alcance de
la subvención.

```text
GitHub main + documentos normativos en inglés = fuente autoritativa
Documentos alemán, francés, español, italiano, ruso y chino = traducciones y ayudas de lectura
```

En caso de discrepancia, se aplica este orden:

1. el código realmente fusionado en GitHub `main`;
2. [TEST_REPORT.md](../../TEST_REPORT.md) para las cifras de tests y cobertura;
3. [docs/STATUS.md](../STATUS.md) para el estado de implementación;
4. los documentos de subvención en inglés para scope, presupuesto y entregables.

Una traducción no debe presentar ninguna capacidad como más fuerte que la fuente
inglesa. Expresiones como «orientado al RGPD», «endurecido», «verificable» o
«local» son descripciones técnicas, no certificaciones jurídicas o de seguridad.

## 🛠️ Convención de mantenimiento

```text
1. actualizar y fusionar primero la fuente inglesa
2. verificar el nuevo main
3. sincronizar las traducciones en un PR docs-only separado
4. no introducir una cifra o claim únicamente en una traducción
```
