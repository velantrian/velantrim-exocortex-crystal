# Glosario de Crystal y disciplina de afirmaciones

- **physical L3**: almacenamiento con varios estados; no es automáticamente **strict Canon**.
- **retrieval score**: señal de ranking, no evidence.
- **model output**: material generado, no source truth.
- **migration proof**: prueba de migración/equivalencia, no claim proof.
- **SQLite**: perfil local-first activo ordinario.
- **Mock**: backend explícito de desarrollo/CI.
- **PostgreSQL/pgvector**: objetivo inactivo opcional con `active=false`; import success no es activation.
- **Reader Core**: capa de lectura prevista y no implementada.
- **NLnet**: submitted / under review / not awarded.
- **aprox. €50,000**: planificación, no presupuesto aprobado ni compromiso de pago; budget change: none.
- **baseline**: trabajo fusionado antes del acuerdo; no se cuenta de nuevo como funded delta.
- No hay certificación legal, GDPR, de seguridad ni native-speaker editorial certification.
