# Resumen del proyecto, la subvención y la gobernanza

Crystal es una infraestructura local-first de memoria, evidencia y límites de decisión para sistemas de IA auditables.

```text
physical L3 != strict Canon
retrieval score != evidence
model output != source truth
migration proof != claim proof
import success != activation
```

SQLite es el perfil local-first activo ordinario. Mock es un backend explícito de desarrollo/CI. PostgreSQL/pgvector sigue siendo un objetivo opcional inactivo con `active=false`; importar con éxito no lo activa.

La propuesta a NLnet fue enviada, está en revisión y no ha sido concedida. Aproximadamente €50,000 es planificación, no un presupuesto aprobado ni un compromiso de pago. Cambio presupuestario: ninguno. El trabajo fusionado antes de un acuerdo es línea base existente y no puede volver a contarse como delta financiado.

Reader Core no está implementado. No existe certificación legal, GDPR o de seguridad, ni certificación editorial de hablantes nativos.
