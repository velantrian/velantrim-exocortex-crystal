# 🇩🇪 Crystal-Glossar

## Authority / Storage

**physical L3** — physische Multi-Status-Graph-/Storage-Surface; physische Präsenz bedeutet keine Mitgliedschaft im **strict Canon**.  
**strict Canon** — deny-dominant trusted read projection.  
**Guardian** — structural/safety admission boundary.  
**TruthGate** — policy admission boundary, kein objective-truth oracle.  
**TrustSnapshot / CanonicalView** — trusted reconciliation/read surfaces.  
**`active=false`** — ein Backend-/Import-Target ist keine ordinary active runtime.

## Reader Core

**Reader Core RC-1** — bounded evidence-linked source/session skeleton.  
**Reader Core RC-2** — source-version-bound caller-supplied Structural Document Map.  
**Reader Core RC-3** — explicit deterministic multi-pass ledger.  
**Reader Core RC-4** — source-linked PRE-ADMISSION proposition candidate registration.  
**Reader Core RC-5** — same-session/same-version explicit relation candidate registry.  
**Reader Core RC-6** — bounded working sets + caller-supplied `SUMMARY` mit direkter RC-4 leaf provenance.  
**Reader Core RC-7** — explicit cross-document candidate links zwischen unterschiedlichen document identities.  
**Reader Core RC-8** — abgeschlossene Retrieval-Architektur-/Research-Entscheidung.  
**Reader Core RC-9** — implementierte deterministische offline BM25 PRE-ADMISSION candidate discovery.  
**Dedicated/full Reader Core** — breiter autonomer semantic Reader; nicht implementiert (`dedicated_reader_core=false`).

## RC-4 / RC-5 Vocabulary

**`EXTRACTED_PROPOSITION`** — RC-4 fidelity class; kein verified fact.  
**source owner** — explizite Author-/Speaker-/Reported-source Attribution.  
**proposition presentation category** — Kategorie der Source-Darstellung, nicht Crystal-Verifikation.  
**`POSSIBLE_CONTRADICTION`** — symmetrische RC-5 suspicion, keine confirmed contradiction.  
**`EXCEPTION`** — directional RC-5 limiter.  
**`QUALIFICATION`** — directional RC-5 refinement.  
**`TENSION`** — symmetric tension candidate.  
**relation rationale** — expliziter Caller-Grund und Audit-Kontext, kein truth proof.

```text
EXTRACTED_PROPOSITION != verified fact
Reader candidate != admitted evidence
contradiction candidate != confirmed contradiction
```

RC-7 kinds: `SUPPORTS`, `CONTRADICTS`, `ELABORATES`, `REFERENCES`, `DEFINES`, `EXAMPLE_OF`, `PREREQUISITE_FOR`, `SAME_TOPIC`, `POSSIBLE_SAME_CLAIM`.

**inspection basis** — descriptive caller metadata, kein numerischer similarity/confidence/identity score.  
**cross-document link provenance** — exact two-sided session/candidate/pass/node/source/locator provenance.

## Retrieval / Evaluation

**RC-9 lexical candidate discovery** — deterministisches in-memory BM25-Ranking über einen Reader proposition snapshot; erzeugt inspection candidates, keine Evidence Verdicts.  
**Evaluation Surface v2** — eingefrorene judged adversarial retrieval surface.  
**Comparator v1** — pinned multilingual semantic comparator; recall recovered, discrimination gate failed.  
**NLI neutral-filter v1** — preregistered bidirectional filter; discrimination improved, useful-recall safety failed.

`LEXICAL_BASELINE_EXPOSES_MEASURED_GAP` — erhaltene RC-9 classification.  
`SEMANTIC_RECALL_RECOVERED_DISCRIMINATION_GATE_FAILED` — Comparator-v1 classification.  
`NLI_NEUTRAL_FILTER_GATE_FAILED` — NLI-v1 classification.

## RRTIC-v1

**Reader Retrieval Typed Inspection Contract v1** — eingefrorener architecture-only typed inspection contract nach dem relation-contract mismatch reassessment.

Relation families: `EQUIVALENCE_SUSPECT`, `RELATED_SUSPECT`, `CONTRADICTION_SUSPECT`, `QUALIFICATION_SUSPECT`, `TOPIC_ONLY_SUSPECT`, `UNKNOWN`.

Qualifier dimensions decken entity/predicate binding, argument roles, polarity, modality/quantifier, temporal/version, jurisdiction, condition direction, units/thresholds und attribution/causality ab. State: `MATCH | MISMATCH | UNKNOWN | NOT_APPLICABLE`.

RRTIC-v1 ist kein Modell, Reranker, truth engine, Accept/Reject-Policy oder Runtime-Provider.

## Critical distinctions

```text
coverage != comprehension proof
pass completion != comprehension proof
EXTRACTED_PROPOSITION != verified fact
Reader candidate != admitted evidence
contradiction candidate != confirmed contradiction
retrieval match != evidence
similarity != identity
ranking != epistemic authority
NLI label != proposition identity
RRTIC suspicion != adjudicated relation
qualifier mismatch != truth decision
evaluation pass != runtime authorization
```

Historische RC-7-Kompatibilität:

```text
cross-document link != Canon relation
same-topic != same proposition
possible-same-claim != claim identity
similarity signal != identity proof
repetition across sources != corroboration
```
