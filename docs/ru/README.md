Английский остаётся первичным рабочим источником и разрешает расхождения, но Crystal не является English-only проектом. [Русский README](../../README.ru.md) — первый полноформатный перевод со статусом `CURRENT`: он сохраняет визуальную структуру, mindmap, ASCII-схемы, таблицы, ограничения и навигацию английской версии.

Остальные документы переводятся поэтапно. Наличие файла в этой папке не доказывает его актуальность. Пока конкретный документ не проверен против указанного английского checkpoint, считать его `REFRESH_NEEDED`.
