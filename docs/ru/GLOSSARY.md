# 🇷🇺 Crystal — глоссарий

**physical L3** — multi-status physical storage; не тождествен strict Canon.  
**strict Canon** — deny-dominant trusted read projection.  
**active=false** — PostgreSQL target не является ordinary active runtime.

**Reader Core RC-1** — exact source/session/provenance skeleton.  
**Reader Core RC-2** — caller-supplied structural map.  
**Reader Core RC-3** — explicit deterministic multi-pass ledger.  
**Reader Core RC-4** — source-linked PRE-ADMISSION proposition candidate layer.  
**Reader Core RC-5** — same-session/same-version PRE-ADMISSION relation candidate registry.

**EXTRACTED_PROPOSITION** — fidelity class RC-4; не verified fact.  
**source owner** — explicit attribution того, чьё утверждение представлено.  
**proposition presentation category** — как источник подаёт proposition; не Crystal truth verdict.

**POSSIBLE_CONTRADICTION** — symmetric suspicion; не confirmed contradiction.  
**TENSION** — tension без утверждения contradiction.  
**EXCEPTION** — directional: right candidate — исключение к left.  
**QUALIFICATION** — directional: right candidate уточняет/сужает left.  
**relation rationale** — audit reason регистрации, не evidence of truth.

```text
Reader candidate != admitted evidence
contradiction candidate != confirmed contradiction
similarity != identity
repetition != corroboration
```

**dedicated/full Reader Core** — автономный Semantic Reader; остаётся not implemented.
