# Guide des références étendues

Ce guide oriente vers les sources anglaises détaillées sans dupliquer les preuves volatiles. `CURRENT` désigne un contenu maintenu, `RETIRED` un historique non autoritatif et `ENGLISH_ONLY_BY_DESIGN` un détail technique, juridique ou d’audit conservé en anglais.

Limites : physical L3 != strict Canon ; retrieval score != evidence ; model output != source truth ; migration proof != claim proof ; import success != activation. SQLite est le profil local-first actif ordinaire, Mock sert au développement/CI et PostgreSQL/pgvector reste inactif avec `active=false`. Reader Core n’est pas implémenté.

NLnet : submitted / under review / not awarded. Environ €50,000 relève de la planification, pas d’un budget approuvé ni d’un engagement de paiement ; budget change: none ; la baseline fusionnée avant accord ne redevient pas funded delta. Aucune legal/GDPR/security ni native-speaker editorial certification.
