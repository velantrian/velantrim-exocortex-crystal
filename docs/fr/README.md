L’anglais est l’unique langue de travail normative de Crystal. Le corpus complet n’est pas
traduit. Le résumé public français actuel est [README.fr.md](../../README.fr.md).

Les fichiers `REVIEWER_GUIDE.md`, `QUICKSTART.md`, `STATUS.md`, `GRANT_OVERVIEW.md` et
`GLOSSARY.md` de ce dossier sont des snapshots best-effort pouvant être en retard. Ils ne sont
pas une source pour les déclarations actuelles de capacité, sécurité, financement ou runtime.

localisation séparée → enregistrement du source checkpoint anglais.
