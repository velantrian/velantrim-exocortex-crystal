# Glossaire Crystal et discipline des affirmations

- **physical L3** : stockage multi-statut, pas automatiquement **strict Canon**.
- **retrieval score** : signal de classement, pas une evidence.
- **model output** : contenu généré, pas une source truth.
- **migration proof** : preuve de migration/équivalence, pas un claim proof.
- **SQLite** : profil local-first actif ordinaire.
- **Mock** : backend explicite de développement/CI.
- **PostgreSQL/pgvector** : cible inactive optionnelle avec `active=false`; import success n’est pas activation.
- **Reader Core** : couche de lecture prévue, non implémentée.
- **NLnet** : submitted / under review / not awarded.
- **environ €50,000** : planification, pas budget approuvé ni engagement de paiement; budget change: none.
- **baseline** : travail fusionné avant accord, non recompté comme funded delta.
- Aucune certification juridique, GDPR, sécurité ou native-speaker editorial certification.
