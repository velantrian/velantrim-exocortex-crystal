# Glossario Crystal e disciplina delle affermazioni

- **physical L3**: archivio multi-stato, non automaticamente **strict Canon**.
- **retrieval score**: segnale di ranking, non evidence.
- **model output**: materiale generato, non source truth.
- **migration proof**: prova di migrazione/equivalenza, non claim proof.
- **SQLite**: profilo local-first attivo ordinario.
- **Mock**: backend esplicito di sviluppo/CI.
- **PostgreSQL/pgvector**: obiettivo opzionale inattivo con `active=false`; import success non è activation.
- **Reader Core**: livello di lettura pianificato, not implemented.
- **NLnet**: submitted / under review / not awarded.
- **circa €50,000**: pianificazione, non budget approvato o impegno di pagamento; budget change: none.
- **baseline**: lavoro merged prima dell’accordo, non ricontabile come funded delta.
- Nessuna certificazione legale, GDPR, sicurezza o native-speaker editorial certification.
