# Guida ai riferimenti estesi

Questa guida indirizza alle fonti inglesi dettagliate senza duplicare evidenze volatili. `CURRENT` indica materiale mantenuto, `RETIRED` storia non autorevole e `ENGLISH_ONLY_BY_DESIGN` dettaglio tecnico, legale o di audit conservato in inglese.

Confini: physical L3 != strict Canon; retrieval score != evidence; model output != source truth; migration proof != claim proof; import success != activation. SQLite è il profilo local-first attivo ordinario, Mock serve sviluppo/CI e PostgreSQL/pgvector resta inattivo con `active=false`. Reader Core non è implementato.

NLnet: submitted / under review / not awarded. Circa €50,000 è pianificazione, non budget approvato o impegno di pagamento; budget change: none; la baseline merged prima dell’accordo non torna funded delta. Nessuna legal/GDPR/security o native-speaker editorial certification.
