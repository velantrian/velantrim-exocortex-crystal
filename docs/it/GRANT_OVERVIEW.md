# Panoramica di progetto, finanziamento e governance

Crystal è un’infrastruttura local-first per memoria, evidenze e confini decisionali in sistemi di IA verificabili.

```text
physical L3 != strict Canon
retrieval score != evidence
model output != source truth
migration proof != claim proof
import success != activation
```

SQLite è il profilo local-first attivo ordinario. Mock è un backend esplicito per sviluppo/CI. PostgreSQL/pgvector resta un obiettivo opzionale inattivo con `active=false`; un import riuscito non è attivazione.

La proposta NLnet è stata presentata, è in revisione e non è stata assegnata. Circa €50,000 è una stima di pianificazione, non un budget approvato né un impegno di pagamento. Variazione di budget: nessuna. Il lavoro unito prima di un accordo è baseline esistente e non può essere conteggiato di nuovo come delta finanziato.

Reader Core non è implementato. Non sono rivendicate certificazioni legali, GDPR o di sicurezza, né certificazioni editoriali di madrelingua.
