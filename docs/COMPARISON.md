# Comparison

Velantrim Crystal should be evaluated as a verifiable AI memory core, not as a chatbot product.

## Short comparison

| System type | Main strength | Limitation Crystal addresses |
|---|---|---|
| ChatGPT-style assistant | fluent generation | memory is not a verifiable local truth store |
| Traditional RAG | retrieves text chunks | chunks are not the same as canonical, source-tracked memory |
| Vector database | semantic similarity | similarity is not provenance or truth validation |
| Notes app | human-readable notes | notes are not an auditable AI memory pipeline |
| Agent memory frameworks | agent continuity | often weaker separation between claim, evidence, epistemic state and canonical truth |
| Velantrim Crystal | verifiable local memory | focuses on TruthGate, provenance, receipts and local control |

## Core difference

Many systems answer the question:

```text
How can an AI remember more?
```

Velantrim Crystal asks a stricter question:

```text
What is allowed to become persistent AI memory, and why?
```

## Why this matters

Long-term AI memory can amplify mistakes. If unsupported claims become persistent memory, future answers inherit those errors.

Crystal therefore separates:

- raw input
- observed claim
- source status
- epistemic state
- evidence
- canonical graph entry
- traceable answer

## Positioning

The project is best described as:

```text
local-first verifiable memory infrastructure for trustworthy AI systems
```

It should not be positioned as a full AGI, a social chatbot, or a replacement for human review.
