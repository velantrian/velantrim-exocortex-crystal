# 扩展参考指南

本指南指向详细英语来源，而不复制易变的 evidence。`CURRENT` 表示维护中的资料，`RETIRED` 表示非权威历史，`ENGLISH_ONLY_BY_DESIGN` 表示按设计保留英语的技术、法律或审计细节。

边界：physical L3 != strict Canon；retrieval score != evidence；model output != source truth；migration proof != claim proof；import success != activation。SQLite 是普通活跃 local-first 配置，Mock 用于开发/CI，PostgreSQL/pgvector 以 `active=false` 保持非活跃。Reader Core 尚未实现。

NLnet：submitted / under review / not awarded。约 €50,000 仅为规划，不是获批预算或付款承诺；budget change: none；协议前已 merged 的 baseline 不能再次算作 funded delta。没有 legal/GDPR/security 或 native-speaker editorial certification。
