यह हिन्दी reviewer के लिए summary है। Legal, contractual और grant-scope authority अंग्रेज़ी दस्तावेज़ों की है।

## वर्तमान status

Velantrim Crystal को NLnet NGI0 Commons Fund में submit किया गया है और यह review में है।
Repository funding award, signed contract या confirmed payment का दावा नहीं करती।

## Governing formula

```text
BASELINE TODAY
    +
MEASURABLE FUNDED DELTA
    =
INDEPENDENTLY VERIFIABLE DELIVERABLE
```

पहले से merged features, tests, documentation और security hardening baseline हैं।
उन्हें future paid deliverables के रूप में दोबारा नहीं गिना जाता।

## Baseline के उदाहरण

Current public baseline में, authoritative अंग्रेज़ी sources के अनुसार, शामिल हैं:

- local-first L0/L1 memory;
- local L3 backend;
- Guardian / TruthGate admission control;
- CanonicalView, TRACE और Receipt;
- evidence span, review queue और import session;
- GDPR-संबंधित erasure / restriction mechanisms;
- deterministic evaluation / CI gates;
- optional FastAPI / MCP surfaces;
- strict read-only HTTP query path।

यह सूची नया scope नहीं बनाती; यह current `main` और अंग्रेज़ी status का summary है।

## Funded delta requirements

किसी funded delta को:

- baseline से स्पष्ट रूप से अलग होना चाहिए;
- measurable acceptance criteria रखने चाहिए;
- independent reviewer द्वारा reproducible होना चाहिए;
- test / evaluation evidence रखना चाहिए;
- TruthGate, provenance या query boundary को कमजोर नहीं करना चाहिए;
- अलग issue / RFC / PR के change control से गुजरना चाहिए;
- authoritative budget और milestone documents से मेल खाना चाहिए।

## स्वतः scope में न जुड़ने वाली चीज़ें

सिर्फ documents या research notes में मौजूद होने से निम्न items funded scope नहीं बनते:

- Titan / Full Personal Exo-Cortex;
- autonomous cognitive OS;
- NoeticCore / AttentionRouter / BICA;
- neuromorphic / biological cognition claims;
- self-modifying agent;
- universal World Knowledge Core;
- production multi-tenant service;
- legal GDPR certification;
- security certification।

## Replay work classification

Titan deterministic replay work को prior art के रूप में review किया गया है।

```text
REVIEWED_PRIOR_ART
DOCUMENTED_ONLY
M4_CANDIDATE
NO_RUNTIME_CHANGE
NO_CANON_WRITE
NO_BUDGET_CHANGE
BASELINE_NOT_MOVED
```

किसी future Crystal implementation को existing evaluation stack extend करना होगा और
offline, non-authoritative, separate RFC/PR तथा baseline fixed जैसी शर्तें बनाए रखनी होंगी।
