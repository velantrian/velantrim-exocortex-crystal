- authoritative अंग्रेज़ी documentation: `README.md` और `docs/` के अंग्रेज़ी दस्तावेज़;
- इस translation का synchronization marker: `main@c5a34a64`;

production readiness का अतिरिक्त दावा नहीं करता।
