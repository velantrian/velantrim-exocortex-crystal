# Prototypes

This directory contains research prototypes and biological-memory analogy
experiments for future Velantrim ExoCortex directions. These files are **not**
part of the Crystal runtime pipeline unless explicitly imported by production
modules.

They are kept to document research ideas and explorations, not to claim
implemented behaviour.

| Module | RFC | Status |
|---|---|---|
| `fractal_memory_layer.py` | RFC0070 | Prototype — not wired into core pipeline |
| `hybrid_biological_memory.py` | RFC0070–0073 | Prototype facade — not wired into core pipeline |
| `immune_crispr_memory_guard.py` | RFC0072 | Prototype — not wired into core pipeline |
| `neurogenesis_dynamic_growth.py` | RFC0073 | Prototype — not wired into core pipeline |

`TruthGate`, `Guardian`, L3 writes, receipts, and evaluation gates remain the
single source of implemented behaviour in the Crystal open core. See
[`FUTURE.md`](../FUTURE.md#33-integrate-or-retire-the-biological-prototypes)
for the research roadmap for these modules.
