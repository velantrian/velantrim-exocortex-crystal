# Prototypes

This directory contains retained research prototypes and biological-memory analogy experiments. These files are **not** part of the Crystal runtime pipeline unless explicitly imported by production modules.

They are kept as research evidence and historical design material, not to claim implemented behaviour and not to create an automatic future roadmap.
